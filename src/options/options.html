🔑 GitHub Fine-Grained Token Guide

Least Privilege

Follow these steps to generate a GitHub Fine-Grained Personal Access Token (PAT) for LeetArchive:

  1. Open GitHub's Fine-Grained Personal Access Token creation page:
    ↗️ Open Fine-Grained PAT Page on GitHub
  2. Give the token a descriptive Token name (for example, LeetArchive).
  3. Under Repository access, choose Only select repositories.
  4. Select your dedicated repository (e.g. leetcode-solutions).
  5. Grant access to only that repository.
  6. Set minimum repository permissions:
    • Contents → Access: Read and write
    • Metadata → Access: Read-only
  7. Recommended: Select No expiration (or set a custom expiration date).
  8. Generate the token, copy it, and paste it into Section 1 below.

🛡️ Why these permissions?

Single Repository Access

Restricts LeetArchive to your chosen repository only, enforcing strict least-privilege security.

Contents Read & Write

Allows LeetArchive to commit problem descriptions and code solution files.
